# 📈 The Stack Keeps Changing

I don't really have a single fixed stack.

If a project needs something I don't know, I learn it.

That's how I ended up going from:

**HTML/CSS → JavaScript → PHP/MySQL → Vue → Node/FastAPI → Raspberry Pi → AI → embeddings → vector databases → Docker → VMs**

which was apparently a perfectly reasonable sequence of events.

# 🧠 Development Philosophy

```text
Have an idea
    ↓
Build it
    ↓
It breaks
    ↓
Google / Docs / AI
    ↓
Understand why it broke
    ↓
Fix it
    ↓
Make it unnecessarily ambitious
    ↓
Repeat
```

I use **ChatGPT** and **GitHub Copilot** heavily during development for research, debugging, architecture exploration, code review, and implementation.

But the goal is always to understand what I'm building, not just paste whatever an AI generated and pray to the dependency gods.
